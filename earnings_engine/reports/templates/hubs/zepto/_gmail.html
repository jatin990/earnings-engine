⚠️

Google OAuth Credentials Required

To link a Gmail account, please configure your Google Cloud Console OAuth 2.0 Client credentials in your root .env file:

# Google Cloud Console -> Credentials -> OAuth 2.0 Client ID
GOOGLE_CLIENT_ID="your-client-id.apps.googleusercontent.com"
GOOGLE_CLIENT_SECRET="your-client-secret"
GOOGLE_REDIRECT_URI="http://localhost:8000/api/v1/zepto/gmail/callback"

Ensure the Authorized Redirect URI in Google Cloud Console is set to http://localhost:8000/api/v1/zepto/gmail/callback (or your deployment domain).
